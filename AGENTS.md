# Instructions for AI agents

When working on business analysis, system analysis, functional requirements, workflow, Jira, UAT, architecture, or technical documentation in this repository:

1. Read `SKILL.md` and apply it as the working standard.
2. Use the user's current project data and instructions as the factual source.
3. For Indonesian outputs, apply section 3A (Anti-AI Slop).
4. For sequence diagrams, apply section 8 and consult `docs/sequence-diagrams.md`.
5. For Word/PDF outputs, apply section 14 and consult `docs/word-pdf-style.md`.
6. Distinguish `Existing / Observed`, `Confirmed`, `Proposed`, and `Need Confirmation`.
7. Never present illustrative API paths, roles, statuses, or business rules as verified project facts.
8. Keep outputs as short as practical while preserving testability and important exceptions.

`SKILL.md` is the canonical instruction source. This file is a pointer, not a competing specification.
